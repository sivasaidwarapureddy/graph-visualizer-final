# Graph Visualizer 🚀 LIVE at - https://graph-frontend-yv3f.onrender.com/

A full-stack interactive graph visualization tool built using React and Spring Boot.

## 📌 Features

- BFS Traversal Visualization
- DFS Traversal Visualization
- Real-time Queue Visualization
- Real-time Stack Visualization
- Animated Node & Edge Traversal
- Dynamic Graph Creation
- Backend-driven Algorithm Execution
- Responsive UI with React Flow

---

## 🛠️ Tech Stack

### Frontend
- React.js
- React Flow
- Tailwind CSS
- Axios

### Backend
- Spring Boot
- Spring Data JPA
- MySQL
- REST APIs
